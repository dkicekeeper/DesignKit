# Gallery P1: search, app presets, canvas context Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Find any of the 207 component pages by typing; preview the Gallery as Tenra, Dalada,
Platina (Plasma) or a custom accent with the right surfaces in one menu; see a component on the
page, in a card or on a hero colour from its canvas.

**Architecture:** `ComponentIndex` also keeps each page's summary and a search over names,
summaries and aliases; the home screen gets `.searchable` and shows matches instead of the
sections. `GalleryTheme` becomes a preset that sets accent and surface together, plus a custom
case. `PreviewCanvas` gets a context picker next to the light/dark switch.

**Tech Stack:** SwiftUI (Gallery app, xcodegen), swift-testing (Gallery's SnapshotTests target hosts `ChangelogTests`-style unit tests).

**Spec:** `docs/superpowers/specs/2026-11-25-colors-mercury-refresh-gallery-design.md` (part C).

## Global Constraints

- Presets: Tenra = `.indigo` + `.glass`; Dalada = light `#2E8B57` / dark `#3CB371` + `.fill`;
  Platina = light `#D6006F` / dark `#FF4FA0` + `.fill`; Custom = a `ColorPicker` accent + a
  glass/fill switch.
- Canvas contexts: Screen (as today), Card (`.cardContentPadding().cardStyle()` under the current
  surface), On colour (`AppColors.accent` behind, `\.heroTone = .onColor`). No sheet emulation.
- Search matches case- and diacritic-insensitively; a component's skeleton name, its 1.x name
  with `View` and `.ds` prefix find its page (same rules as `ComponentIndex.link(for:)`).
- Platina's `#3573BA` is replaced everywhere in the repo (Gallery, CLAUDE.md, docs).

## Review Focus

1. A search with no match: an empty state saying nothing matches the text, not a blank list —
   `GallerySearchTests.noMatch` (index returns `[]`) and the view shows `ContentUnavailableView.search`.
2. A page title with " · " (two components) is found by either name — `GallerySearchTests.eitherName`.
3. Switching preset while a page is open re-renders it with the new accent (the root's `.id` already
   does this; the custom accent's binding sets `DesignKitTheme.accent` before the state change).
4. "Card" context for a component that is itself a card: a card in a card; acceptable, the
   context's hint says so.
5. Foundations pages (Colors, Typography, …) are found by their titles — `GallerySearchTests.foundations`.
