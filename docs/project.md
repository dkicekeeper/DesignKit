# DesignKit

The SwiftUI design system shared by Tenra, Dalada and Platina: tokens, components, a Gallery app
that shows every component, and the tooling the apps run (lint, migrations, the agent block). One
package, no app logic. Its consumers and how each depends on it: [CLAUDE.md](../CLAUDE.md).

Now: releases are numbered at merge by the release bot; the apps follow by their DesignKit update
workflows. Open work: [backlog/](backlog/).
