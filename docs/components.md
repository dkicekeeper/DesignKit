## Actions

### DSButton

The button of the design system: a title with an icon before, after or above it (or the icon alone), appearance × role × size, a loading state, full width or its own.

Since 2.0.0 · Apps: Dalada, Tenra

- `DSButton` in `Sources/DesignComponents/Actions/DSButton.swift`
  A button of the design system.

```swift
init(_ title: String, systemImage: String? = nil, iconPlacement: IconPlacement = .leading, appearance: Appearance = .primary, role: Role = .normal, size: Size = .large, shape: Shape = .automatic, fullWidth: Bool = false, isLoading: Bool = false, isDisabled: Bool = false, action: @escaping () -> Void)
```

- Loading keeps the button's width, shows a spinner and blocks taps: DSButton("Save", isLoading: saving).
- Icon on top draws a tile (the actions under a detail screen's hero; EntityActionButton before 2.0). Give it the width: a row of them in an HStack.
- A delete-selected bar: DSButton("Delete (3)", role: .destructive, shape: .capsule, fullWidth: true) (BulkDeleteButton before 2.0).
- A press plays a light haptic, a warning one for a destructive button.

### SearchablePicker

A list too long to scan: the system search narrows it, one option or several are picked with the row's circle, and a name nothing has offers “Create”.

Since 8.9.0 · Apps: none yet

- `SearchablePicker` in `Sources/DesignComponents/Selection/SearchablePicker.swift`; skeleton `SearchablePickerSkeleton`
  A list to pick one option or several from, with the system search and "Create “…”".

```swift
init(_ options: [Option], selection: Binding<Value?>, prompt: String? = nil, dismissesOnSelection: Bool = false, onCreate: ((String) -> Value?)? = nil)
init(_ options: [Option], selection: Binding<Set<Value>>, prompt: String? = nil, onCreate: ((String) -> Value?)? = nil)
```

- A screen's content: put it in a NavigationStack (a pushed screen, or a sheet with its own stack), where the search field lives.
- selection: Binding<Value?> picks one (dismissesOnSelection: true closes the screen on a pick); Binding<Set<Value>> picks several.
- The search keeps the options whose title or subtitle contains the text, any case, any accents. onCreate adds the typed name and returns its value, which is picked.
- Loading: SearchablePickerSkeleton. Strings: picker.search, picker.create, picker.noResults.

- Do: Use it when the list is too long to scan (about 10 options and more).
- Do: Pass onCreate when a person can add the missing option (a category, a tag).
- Don't: Use it for a few options: a menu row or ChipPicker shows them at once.
- Don't: Put it outside a NavigationStack: the search field lives in the navigation bar.
